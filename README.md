# RUSHLINE

Carrera arcade original hecha en Godot.

- Jugar en el navegador: https://stillset9.github.io/rushline/
- Windows (ejecutable original 1.0.0): https://github.com/Stillset9/rushline/releases/tag/1.0.0

## Windows

Descargá `RUSHLINE.exe` del Release. Creá una carpeta `music` al lado del ejecutable y poné ahí los `.ogg` y `CREDITS.txt` del mismo Release. Las portadas van en `music/covers/`.

Sin esa carpeta el juego abre igual, y la música se descarga de esta versión web.
